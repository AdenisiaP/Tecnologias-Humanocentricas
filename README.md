# 🛡️ Tecnologias Humanocêntricas

Este repositório reúne quatro protótipos de aplicações digitais criados com um único propósito: **atender às necessidades humanas reais, respeitando princípios, valores e a saúde emocional dos usuários, de forma 100% gratuita e acessível.**

Nenhum desses projetos possui fins lucrativos, anúncios, algoritmos de engajamento predatório ou rastreamento de dados privados. Eles foram desenhados para funcionar como Bens Públicos Digitais.

---

## 🚀 Protótipos Criados (Validados e Funcionais)

Você pode testar a interface e a lógica inicial de cada ferramenta diretamente no navegador através dos links abaixo:

1. **🛡️ Protetor de Direitos Universal:** Analisador local de contratos e cobranças para identificar cláusulas abusivas e proteger o cidadão frente à burocracia.
   * [Testar Protótipo no CodePen](https://codepen.io)
2. **🤝 Rede de Apoio Comunitário:** Painel hiperlocal e descentralizado para conectar vizinhos para empréstimos de ferramentas, doações e ajuda mútua sem filtros comerciais.
   *[Testar Protótipo no CodePen](https://codepen.io)
3. **🌱 Espaço de Acolhimento Seguro:** Interface anônima de escuta ativa e triagem emocional, com exercícios de respiração guiada e ponte direta para canais oficiais gratuitos (como o CVV).
   * • [Testar Protótipo no CodePen](https://codepen.io)
4. **🧼 Despoluidor de Informação:** Filtro inteligente que intercepta manchetes sensacionalistas e as reescreve de forma puramente factual, mitigando gatilhos de pânico e ansiedade.
   * [Testar Protótipo no CodePen](https://codepen.io)

## 🙋 Convocação para Programadores e Designers Voluntários

Estes códigos foram estruturados inicialmente em HTML, CSS e JavaScript puros rodando no navegador. O objetivo agora é dar escala a essas soluções para que cheguem a instituições, ONGs e pessoas vulneráveis em formato de aplicativos nativos ou sistemas comunitários.

### Como você pode ajudar?
* **Desenvolvimento Mobile:** Ajudar a portar esses conceitos para frameworks como Flutter, React Native ou Kotlin/Swift, permitindo que funcionem offline direto no celular dos usuários.
* **Inteligência Artificial Local:** Implementar modelos de linguagem leves (SLMs como Llama/Gemma) que rodem localmente nos dispositivos (WebLLM/ONNX) para os itens 1, 3 e 4.
* **Redes Descentralizadas (Mesh):** Implementar protocolos ponto a ponto (P2P) ou suporte a redes mesh para o item 2 funcionar mesmo sem internet estável.
* **Design de Interface (UX/UI):** Aprimorar a acessibilidade para idosos, pessoas analfabetas ou com deficiências visuais e motoras.

Se você compartilha da visão de que a tecnologia deve servir como um escudo protetor para a humanidade, sinta-se convidado a abrir uma *Issue*, propor melhorias ou contribuir com código!
